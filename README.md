# Hazo

**Home Assistant Zigbee Orchestrator**

Créez et gérez vos groupes directement sur le réseau Zigbee.

## Le nom

Hazo signifie **H**ome **A**ssistant **Z**igbee **O**rchestrator. Il rejoint la famille des projets Halo (Light Orchestrator), Havo (Ventilation Orchestrator), Hapo (Presence Orchestrator) et Hano (Notification Orchestrator) pour Home Assistant.

## Objectif

Hazo a pour objectif de permettre la création et la gestion de groupes directement sur le réseau Zigbee depuis Home Assistant.

## État du projet

Le projet démarre. Ce dépôt contient uniquement sa base documentaire ; aucune intégration installable ni fonctionnalité Zigbee n'est encore disponible.
